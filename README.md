# Workboard

A simple web dashboard project using Next JS and React JS with CRUD functionality and comments using an API. Workboard covers projects, tasks and milestones. The use case of this project is software as a service for teams who work together.

## Technologies Used
- Next JS
- React JS
- Bootstrap


## Features
- Creating projects, tasks and milestones
- Editing projects, tasks and milestones
- Deleting projects, tasks and milestones
- Allowing users to comment on projects, tasks and milestones

  ## The Process
  I was given a provided API and given the task to create a project that fully utilises the API so I decided to systemically go through each provided end point and created this simple first version of Workboard. As a first version, there is still much I can improve on such as the layout in some sections like the individual tasks page along with optimising the app. Overall, the project was a good learning experience for building of scale.


  ## How to Set it Up
  1. Clone the repository
  2. Run npm install for the dependencies
  3. Run the development server npm run dev
  4. Open the local url
